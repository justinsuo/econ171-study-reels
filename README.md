# ECON 171 Study Reels

[Watch the study reels](https://justinsuo.github.io/econ171-study-reels/)

36 short vertical videos with narration, diagrams, captions, and multiple-choice recall questions. Scroll or swipe between reels, change playback speed, and search by topic.

Missed concepts return sooner. Correct answers receive a lower, nonzero review weight. Quiz progress is stored only in the current browser; it does not sync between devices.

## Run locally

Serve this folder with any static HTTP server, for example `python -m http.server 8000`, then open `http://localhost:8000`. The live site uses GitHub Pages from the root of the `main` branch.

## Files

- `index.html`, `style.css`, `app.js`: the player and adaptive quiz behavior
- `reels.json`: explanations, questions, answers, and course-source references
- `videos/`: 36 captioned MP4 videos
- `posters/`: preview images

## Scope

A study aid based on the assigned reading ranges, slides, worksheets, and practice materials reviewed for ECON 171 Midterm 2. It is not an official course resource or a prediction of exam questions. Each reel lists its source. Supplemental Section 6 was inaccessible; IV and RD explanations use the papers and lectures. No original course PDFs, account credentials, or saved quiz history are included.
